烧录步骤（一句话版）

  1. 装 ESP-IDF v5.4+ 开发环境
  2. idf.py set-target esp32s3
  3. idf.py menuconfig → 选 Bread Compact WiFi (面包板) → 保存退出
  4. idf.py build（约 5 分钟）
  5. 按住 BOOT 键不松手，插入 USB，等 2 秒松手
  6. idf.py flash
  7. 烧完后打开串口监视器：idf.py monitor
  8. 手机会搜到 "xiaozhi-xxxx" 的 Wi-Fi 热点，连上 → 输你家 Wi-Fi 密码 → 完成
⚡ 免编译捷径：小智官方 GitHub Releases 页面有预编译的 .bin 固件包（面包板专用），下载后用乐鑫官方烧录工具 ESP Flash Download Tool 烧进去，跳过安装 ESP-IDF。

实物效果

接好后大概长这样：面包板中间插 ESP32-S3 开发板，周边散落麦克风模块、功放模块、OLED 屏、两个按键。全部用彩色杜邦线连接，像一团彩色意大利面，但能用。

通电后屏幕会显示"小智 AI"启动画面，连上 Wi-Fi 后说 "hi echo" 就能唤醒对话。
