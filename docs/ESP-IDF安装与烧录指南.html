适用硬件：ESP32-S3 开发板（面包板方案）｜适用固件：小智 AI v2.2.3（bread-compact-wifi 板卡）

二、安装 ESP-IDF 环境

重要前提：小智 v2.x 要求 ESP-IDF 5.4.0 或更高版本。低于 5.4（如 5.3.x）执行 idf.py set-target 会报错：project depends on idf (>=5.4.0) which doesn't match any versions。

第 1 步：下载离线安装包

访问乐鑫官方下载页：

https://dl.espressif.com/dl/esp-idf/

往下找到 Windows 离线安装包，文件名类似：

esp-idf-tools-setup-offline-5.4.1.exe
  • ⚠️ 认准 Offline Installer（离线版，约 1.5~2GB），不要选 Online 版（在线版安装时联网下载，易失败）
  • 版本选 5.4.x（5.4.0 或 5.4.1 均可），不要选 5.3 或更老

第 2 步：运行安装程序

  • 双击安装包，一路点 Next，全部使用默认选项
  • 安装路径保持默认 C:\Espressif（不要改，避免中文或空格路径出问题）
  • 勾选安装 USB 驱动（烧录必需）
  • 等待安装完成（约 10~20 分钟）

第 3 步：验证安装

安装完成后，在 Windows 开始菜单会看到新快捷方式：

ESP-IDF 5.4 CMD

双击打开它（黑色命令行窗口），输入：

idf.py --version

如果显示 ESP-IDF v5.4.1 之类的版本号，即安装成功。

关键概念：ESP-IDF 环境不是全局的。每次编译前，必须先打开 "ESP-IDF 5.4 CMD" 专用窗口，再在里面敲命令。普通 PowerShell 是找不到 idf.py 的。

三、切换芯片目标（C5 → S3）

你手上的工程之前是按 ESP32-C5 配置的，现在要切换到 ESP32-S3。在 "ESP-IDF 5.4 CMD" 窗口里进入工程目录：

cd "c:\Users\phorh\Desktop\情感陪伴机器人\esp32-main\xiaozhi-esp32-main"
idf.py set-target esp32s3
说明：set-target 会重新生成 sdkconfig，之前 C5 的配置会重置，这是正常现象，后面重新选板卡即可。

四、选择板卡 + 屏幕型号

继续在同一个窗口执行：

idf.py menuconfig

会弹出一个图形配置菜单（键盘上下键选择，回车进入，空格勾选）：

菜单路径选择项
Xiaozhi Assistant → Board TypeBread Compact WiFi (面包板)
Xiaozhi Assistant → OLED 型号勾选 CONFIG_OLED_SSD1306_128X64（0.96 寸）

操作要点：

  • 上下方向键移动光标
  • 回车键进入子菜单
  • 空格键勾选/取消选项
  • 最后按 S 保存 → Q 退出
OLED 型号判断：0.96 寸屏幕标准分辨率为 128×64，对应 CONFIG_OLED_SSD1306_128X64。128×32 那种是 0.91 寸屏，别选错。

五、编译固件

idf.py build

首次编译会比较慢（要编译整个框架，可能 10~30 分钟），后续增量编译会快很多。看到类似 Project build complete 即成功。

常见报错处理：
  • 编译错误 → idf.py clean 后再 idf.py build
  • 找不到 idf.py → 确认打开的是 "ESP-IDF 5.4 CMD" 窗口
  • 版本过旧报错 → 确认装的 ESP-IDF ≥ 5.4.0

六、烧录固件

先把 ESP32-S3 板子用 Type-C 数据线连到电脑，然后：

idf.py -p COM3 flash

⚠️ COM3 要换成你板子实际的串口号。查串口号方法：设备管理器 → 端口（COM 和 LPT）→ 看插入板子后新出现的 "COMx"。

找不到串口？通常是 USB 驱动没装好。确认安装 ESP-IDF 时勾选了驱动安装。或者板子用的串口芯片是 CH340/CP2102，需要单独装对应驱动。

七、配网 + 测试对话

烧录完成后，板子会自动重启并进入配网状态：

  1. 手机打开 Wi-Fi，连接板子发出的热点 Xiaozhi-xxxx
  2. 浏览器访问 http://192.168.4.1 进入配网页面
  3. 选择你家路由器 Wi-Fi，输入密码，点连接
  4. 板子 3 秒后自动重启，自动连上路由器
  5. 喊一声「你好，小智」，板子亮蓝灯（连服务器）→ 亮绿灯（播放语音）
现象含义排查方向
没亮蓝灯麦克风有问题检查 INMP441 接线（WS=4, SCK=5, SD=6）
蓝灯常亮没连上服务器检查 Wi-Fi 是否连上
连上但没声音喇叭/功放问题检查 MAX98357 接线（DIN=7, BCLK=15, LRC=16）
