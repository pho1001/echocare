第一章 硬件总览与技术规格

1.1 产品定位

Moji 2.0 是一款桌面级 AI 语音助手，由开源社区创作者 Movecall 设计。它基于乐鑫 ESP32-C5 芯片，运行"小智 AI"开源固件，通过 Wi-Fi 连接云端大语言模型（如通义千问 Qwen、DeepSeek），实现自然语音对话。

1.5 寸圆形视网膜屏幕可显示动态表情，配合 ES8311 音频编解码器实现全双工语音交互。整机尺寸小巧（约 46×46mm），适合作为桌面伴侣。

2.2 原理图模块分解

2.2.1 ESP32-C5 主控区域

原理图中心是 ESP32-C5 QFN48 封装芯片。它集成了 RISC-V 处理器核心、Wi-Fi 6 基带、蓝牙 LE、SPI/I2C/I2S 等外设接口。芯片周围分布着去耦电容（多个 100nF + 1µF），确保供电稳定性。

关键引脚连接：

  • 电源：VDD3P3 接 3.3V 稳压输出，VDD_SPI 接 Flash 供电
  • 时钟：外接 40MHz 晶振，提供系统主时钟
  • Flash：通过 SPI 总线连接 16MB NOR Flash
  • 天线：PCB 板载天线（倒 F 型），匹配网络包含 π 型滤波电路

2.2.2 音频链路 — ES8311 区域

音频是 Moji 2.0 最复杂也是出错率最高的区域。全链路为：

[硅麦] ──差分模拟信号──► [ES8311 ADC] ──I2S──► [ESP32-C5] │ [喇叭] ◄──PWM放大──── [ES8311 DAC] ◄──I2S── [ESP32-C5]

ES8311 是顺芯半导体（Everest-semi）的低功耗音频 Codec，通过 I2C（GPIO 26 SDA + GPIO 27 SCL）配置寄存器，通过 I2S（5 根线：MCLK/BCLK/WS/DIN/DOUT）传输音频数据。

⚠ 焊接难点：ES8311 是 QFN-20 封装（引脚在芯片底部），必须用热风枪或加热台焊接，普通电烙铁无法完成。虚焊是"没有声音"的头号原因。

2.2.3 显示接口 — QSPI 区域

屏幕采用 FPC 排线插座连接（零焊接），通过 QSPI（Quad SPI）协议驱动 ST77916 显示控制器：

  • SCLK（GPIO 0）— 时钟线
  • D0/D1/D2/D3（GPIO 9/8/7/6）— 4 根数据线，一次传 4 bit，比普通 SPI 快 4 倍
  • CS（GPIO 3）— 片选
  • RESET（GPIO 1）— 复位
  • 背光（GPIO 2）— PWM 调光

2.2.4 电源管理区域

采用 DC-DC Buck 降压方案，将锂电池电压（3.7~4.2V）稳压到 3.3V 供全板使用。Type-C 口的 VBUS 经充电管理电路为电池充电。GPIO 4 连接 ADC1 通道 3，用于分压检测电池电量。

第四章 核心芯片与外围电路详解

4.1 ESP32-C5 主控芯片

ESP32-C5 是乐鑫 2024 年推出的 RISC-V 单核 Wi-Fi 6 芯片，定位为 IoT 和 AIoT 应用：

  • 处理器：32 位 RISC-V 单核，最高 240MHz，内置 FPU
  • 内存：384KB SRAM（片上），支持外挂 QSPI PSRAM
  • Wi-Fi：802.11ax（Wi-Fi 6），2.4GHz / 5GHz 双频，20MHz 带宽
  • 蓝牙：Bluetooth 5.0 LE，支持 Mesh
  • 外设接口：SPI×3、I2C×2、I2S×2、UART×2、ADC×6、LEDC×6、RMT×4、USB Serial/JTAG
  • Moji 2.0 中的配置：固件编译参数中设置了 Flash 16MB、Quad SPI PSRAM 80MHz、SPI Flash 频率限制 240MHz

4.2 ES8311 音频编解码器

参数值
采样率输入/输出均为 24kHz（AUDIO_INPUT_SAMPLE_RATE / AUDIO_OUTPUT_SAMPLE_RATE）
I2C 地址ES8311_CODEC_DEFAULT_ADDR（0x18）
麦克风类型模拟硅麦（差分输入经 ES8311 内部 ADC 数字化）
功放控制GPIO 5 高电平使能 PA
音频总线标准 I2S（4 线：MCLK + BCLK + WS + DATA）

ES8311 工作流程：

  1. 模拟麦克风信号 → ES8311 内部 PGA 放大 → ADC 采样 → I2S 数字输出 → ESP32-C5 读取
  2. ESP32-C5 播放音频数据 → I2S 发送 → ES8311 DAC → 模拟输出 → 功放 → 喇叭

4.3 ST77916 显示驱动

ST77916 是 Sitronix 的 LCD 控制器，支持 QSPI 接口。固件中通过大量寄存器初始化命令（lcd_init_cmds[] 数组）完成屏幕的 Gamma 校正、显示区域设置、色彩格式配置等。

5.1 架构分层图

┌────────────────────────────────────────────────┐ │ main.cc │ │ app_main() → Initialize() → Run() │ ├────────────────────────────────────────────────┤ │ Application（大脑总管） │ │ 事件驱动主循环 · 状态机调度 · 协议管理 │ ├──────────┬──────────┬──────────┬──────────────┤ │ Audio │ Display │ Protocol │ DeviceState │ │ Service │ (屏幕) │ (网络) │ Machine │ │ (音频) │ │ │ (状态机) │ ├──────────┴──────────┴──────────┴──────────────┤ │ Board 抽象层 │ │ 每个板卡实现 GetLed/GetDisplay/ │ │ GetAudioCodec/GetBatteryLevel │ ├────────────────────────────────────────────────┤ │ movecall-moji2-esp32c5（你的板子） │ │ config.h + .cc（硬件驱动 + 引脚定义） │ ├────────────────────────────────────────────────┤ │ ESP-IDF 框架（FreeRTOS, SPI, I2C, Wi-Fi...） │ └────────────────────────────────────────────────┘

5.2 关键设计模式

  1. 单例模式：Application、Board、McpServer 均使用 GetInstance()，全局唯一实例。
  2. 策略模式：Board 是抽象基类，不同板卡（Moji2、M5Stack CoreS3 等）各自实现，编译时通过 DECLARE_BOARD() 宏注册。
  3. 观察者模式：状态机通过 AddStateChangeListener() 注册回调，状态变化时自动通知。
  4. 事件驱动：主循环使用 FreeRTOS Event Group 等待事件位，无事件时阻塞休眠省电。

第六章 main.cc — 系统入口

6.1 完整源码与逐行注释

// ========== main.cc ==========
#include "application.h"

extern "C" void app_main(void)  // ESP-IDF 的 C 入口点
{
    // 1️⃣ 初始化 NVS Flash（存 Wi-Fi 密码等持久数据）
    esp_err_t ret = nvs_flash_init();
    if (ret == ESP_ERR_NVS_NO_FREE_PAGES  // Flash 没空间了
     || ret == ESP_ERR_NVS_NEW_VERSION_FOUND) { // 版本不兼容
        // 擦除 NVS 分区，重新来过
        nvs_flash_erase();
        ret = nvs_flash_init();  // 再试一次
    }
    ESP_ERROR_CHECK(ret);  // 还失败就死在这里（红灯报警）

    // 2️⃣ 创建 Application 单例（全局唯一的大脑）
    auto& app = Application::GetInstance();

    // 3️⃣ 初始化所有外设：屏幕、音频、网络、状态机……
    app.Initialize();

    // 4️⃣ 进入事件驱动主循环，永不返回
    app.Run();  // while(true) { 等事件 → 处理事件 }
}

第七章 application.cc — 大脑总管

7.1 Initialize() 初始化 8 步骤

void Application::Initialize() {
    auto& board = Board::GetInstance();
    SetDeviceState(kDeviceStateStarting);  // 状态 = "正在启动"

    // 1️⃣ 初始化屏幕 → 显示"正在启动…"和系统信息
    auto display = board.GetDisplay();
    display->SetupUI();
    display->SetChatMessage("system", SystemInfo::GetUserAgent().c_str());

    // 2️⃣ 初始化音频服务 → 开始后台录音
    auto codec = board.GetAudioCodec();
    audio_service_.Initialize(codec);
    audio_service_.Start();

    // 3️⃣ 注册音频回调 → 唤醒词检测 / 发送音频 / VAD 变化
    AudioServiceCallbacks callbacks;
    callbacks.on_send_queue_available = [this]() {
        xEventGroupSetBits(event_group_, MAIN_EVENT_SEND_AUDIO);  };
    callbacks.on_wake_word_detected = [this](const std::string&) {
        xEventGroupSetBits(event_group_, MAIN_EVENT_WAKE_WORD_DETECTED); };
    callbacks.on_vad_change = [this](bool) {
        xEventGroupSetBits(event_group_, MAIN_EVENT_VAD_CHANGE); };
    audio_service_.SetCallbacks(callbacks);

    // 4️⃣ 注册状态变化监听 → 发事件给主循环
    state_machine_.AddStateChangeListener([this](DeviceState, DeviceState) {
        xEventGroupSetBits(event_group_, MAIN_EVENT_STATE_CHANGED); });

    // 5️⃣ 启动 1 秒定时器（刷新屏幕时间/电池状态栏）
    esp_timer_start_periodic(clock_timer_handle_, 1000000);

    // 6️⃣ 注册 MCP 工具（设备控制功能：音量、亮度…）
    auto& mcp_server = McpServer::GetInstance();
    mcp_server.AddCommonTools();
    mcp_server.AddUserOnlyTools();

    // 7️⃣ 设置网络事件回调 → 扫描/连接/断开 → 更新 UI
    board.SetNetworkEventCallback([this](NetworkEvent, const std::string&) {...});

    // 8️⃣ 异步启动网络连接（Wi-Fi / 4G，不阻塞）
    board.StartNetwork();
    display->UpdateStatusBar(true);
}

7.2 事件驱动主循环 — Run()

┌────────────────── Run() 主循环 ──────────────────┐ │ │ │ while (true) { │ │ bits = xEventGroupWaitBits(所有事件位) ← 等待 │ │ ┌───────────────────────────────────────────┐ │ │ │ if (唤醒词检测) → 开始录音 → 发给云端 → │ │ │ │ if (发送音频) → 把缓存的音频包发给服务器 │ │ │ │ if (VAD变化) → LED 灯状态更新 │ │ │ │ if (网络连接) → 开始激活/OTA 检查 │ │ │ │ if (网络断开) → 关闭音频通道 → 显示断开 │ │ │ │ if (按键按下) → 切换聊天/进入配网模式 │ │ │ │ if (时钟滴答) → 刷新屏幕状态栏/内存统计 │ │ │ │ if (定时任务) → 执行延迟回调 │ │ │ └───────────────────────────────────────────┘ │ │ } │ └────────────────────────────────────────────────────┘

事件位使用 FreeRTOS Event Group，13 个事件位同时监控。当没有事件时，xEventGroupWaitBits(portMAX_DELAY) 使 CPU 进入休眠，功耗极低。

9.4 按键逻辑详解

Moji 2.0 只有一个物理按键（GPIO 28），但支持三种操作模式：

// 单击
boot_button_.OnClick = [this]() {
    if (启动中) → EnterWifiConfigMode();   // 进入配网模式
    else         → ToggleChatState();      // 切换对话（开始/停止）
};

// 长按（按住不放）
boot_button_.OnPressDown = [this]() {
    WakeUp();                              // 唤醒屏幕
    StartListening();                      // 按下说话（对讲机模式）
};

// 松开
boot_button_.OnPressUp = [this]() {
    StopListening();                       // 松手停止录音
};

9.5 如何暴露给上层

每个板卡通过覆写（override）基类的虚函数来提供外设：

virtual Led*        GetLed()         → 返回 LED 对象
virtual Display*    GetDisplay()     → 返回屏幕对象
virtual Backlight*  GetBacklight()   → 返回背光对象
virtual AudioCodec* GetAudioCodec()  → 返回 ES8311 音频对象
virtual bool GetBatteryLevel(...)   → 返回电量/充电状态

10.2 音频参数

  • 采样率：输入输出均为 24kHz（不是常见的 16kHz 或 48kHz）
  • 编码格式：OPUS（高效压缩，适合网络传输）
  • 唤醒词：使用乐鑫 ESP-SR 离线语音唤醒引擎
  • VAD（语音活动检测）：自动判断用户是否说完

第十一章 显示子系统

11.1 屏幕架构

Moji 2.0 使用 1.5 寸圆形 IPS 屏幕，显示系统分为两层：

  • 底层：ESP-IDF 的 esp_lcd_panel API，直接操作 ST77916 寄存器
  • 上层：自定义的 Display / LcdDisplay / LvglDisplay 类层次

CMakeLists.txt 中配置了 LVGL 图形库。启用后，屏幕渲染由 LVGL 接管，支持：平滑动画、抗锯齿字体、GIF 动图解码、JPEG 压缩等。Moji 2.0 的"自定义表情"功能即依赖 LVGL。

12.2 一次完整对话的数据流

用户说"hi echo，今天天气怎么样？" │ ▼ ESP-SR 唤醒词检测 → 触发 MAIN_EVENT_WAKE_WORD_DETECTED │ ▼ 状态切换：Idle → Connecting → Listening │ ▼ 麦克风录音 → ES8311 ADC → I2S → OPUS 编码 → WebSocket 发送 │ ▼ 云端：ASR（语音识别）→ LLM（大模型推理）→ TTS（语音合成） │ ▼ WebSocket 接收 OPUS 音频 → 解码 → I2S → ES8311 DAC → 喇叭播放 │ ▼ 说完自动回到 Idle 状态

第十三章 新模块开发指南

13.1 如何加新功能（不动原有结构）

所有新增功能只改你自己的板卡文件夹（boards/movecall-moji2-esp32c5/），不影响任何其他代码。三个文件，三步走：

步骤一：config.h — 定义引脚

// 在 #endif 之前添加（例如加一个 WS2812 灯环）
#define WS2812_LED_PIN    GPIO_NUM_13    // 用 GPIO 13
#define WS2812_LED_COUNT  8              // 8 颗灯珠

步骤二：.cc 文件 — 初始化驱动

// 在 MovecallMoji2ESP32C5 类中添加成员变量和方法

#include "led/circular_strip.h"   // 复用框架已有驱动

class MovecallMoji2ESP32C5 : public WifiBoard {
private:
    CircularStrip* led_strip_;    // 新外设
    // ... 原有成员 ...

    void InitializeLedStrip() {
        led_strip_ = new CircularStrip(WS2812_LED_PIN, WS2812_LED_COUNT);
    }

public:
    MovecallMoji2ESP32C5() : boot_button_(BOOT_BUTTON_GPIO) {
        // ... 原有初始化 ...
        InitializeLedStrip();     // 加在构造函数末尾
    }
};

步骤三：CMakeLists.txt — 注册编译（如果加了新 .cc 文件才需要）

如果只是在已有 .cc 文件里加代码，则不需要改 CMakeLists.txt。
